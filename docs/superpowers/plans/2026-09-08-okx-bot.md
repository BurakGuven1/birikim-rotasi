Instrument `{id,base,ctVal,lotSz,minSz,tickSz}`. Strategy accepts closed multi-frame context and returns a fully described signal or wait. Risk sizes contracts down and validates RR after costs. Paper uses same replay position kernel; demo adapters isolated until strategy supplied. Missing strategy produces explicit blocked jobs. Guard every API with same-origin and HttpOnly local session; restrict hosts to loopback. Tests: durable restart, lease contention, auth rejection, blocked backtest, no duplicate job effects.

Local unlock, credential readiness, worker status/start instructions, saved risk form, queued public market scan, equity, positions, trades, backtest history. No manufactured opportunities. Mobile layout and accessible input labels.
- [x] 5. Validation and documentation (`docs/okx-bot.md`, `.env.example`, package scripts, `.gitignore`, tests/e2e/bot.spec.ts). Run targeted tests first, full suite, lint, build, public API smoke, worker smoke and desktop/mobile UI. Document private/demo checks unavailable without credentials; no performance claim.

## Test-first examples / contracts

Risk with 200 equity, 0.5% budget, entry 100, stop 99, 0 fees, ctVal 1 and lotSz 0.1 yields 1 contract and 1 USDT risk at both 5x and 10x; leverage only changes margin. minSz 2 rejects that order. RR below 2 rejects. A long 100/99/103 bar spanning both 98 and 104 stops out first.

Backtest strategy evaluated at time T sees no candle whose open time + duration exceeds T; a signal at close T may enter at next candle open T, never at the earlier signal close as an assumed executable fill. One open position per symbol. Missing funding must mark results incomplete for acceptance.

Store: second lease owner cannot claim before lease expiry; old owner cannot heartbeat/release new lease. Duplicate unique signal IDs cannot create a second order intent. Public status contains booleans/missing variable names, never credential values. Cross-origin command returns 403; missing session returns 401.
